# Git Lab Study Notes

## Git Fundamentals
Git is a distributed version control system designed for speed, data integrity, and support for distributed, non-linear workflows.
Unlike centralized systems that store deltas, Git records a snapshot of the entire project state with every commit.

## The Three Git Areas
1. Working Directory: The local sandbox where files are edited.
2. Staging Area (Index): Prepares changes for commit using cryptographic hashes.
3. Git Repository: Permanent historical record stored inside .git directory.
